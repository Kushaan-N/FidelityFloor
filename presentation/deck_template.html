01 the question

Everyone measures how good world models are. Nobody measures how good they need to be.

A "world model" is a system's internal simulator: given the current situation and a plan, it predicts what would happen. Robots and AI agents use them to try out actions in imagination before committing.

The field constantly scores these models on prediction quality. But that leaves the practical question open:

  • How accurate does imagination have to be before planning with it actually works?
  • Are all prediction errors equal — or do some types of error hurt much more than others?
  • The answer should be a curve: decision quality vs. amount of error, one curve per error type.
02 the idea

Use a physics simulator as a world model I can break on purpose

Reality
run the plan in the simulator, perfectly
vs
Imagination
run the same plan again, with a controlled amount of error injected
→
Compare
how far apart did the two outcomes end up?

You can't dial the accuracy of a real learned world model up and down. But a simulator can play both roles: the pristine run is "reality", and a deliberately corrupted second run is the "imperfect imagination."

Because both live in the same simulator, the error is directly measured (in centimeters of outcome difference) — not just a knob setting. That measured error becomes the x-axis of every result.

03 four kinds of error

Real world models fail in different ways — I tested each separately

Error typePlain meaning
Biasthe model is consistently wrong in the same direction — e.g. thinks every push goes 15° off and too far
Noisethe model is randomly wrong — jittery, but right on average
Short horizonthe imagination simply stops early, before the outcome is visible
Blurry picturesthe physics is right but the imagined images are degraded — like a video model's artifacts

Each type has three strengths (mild → severe), and I verified the measured error actually grows with each step before trusting any results.

04 the test

Can you still pick the best plan using a flawed imagination?

  • For each of 30 starting scenarios, I generated 12 candidate plans — one good one, several increasingly-off variants, a few random ones.
  • True quality of each plan: run it in the perfect simulator, see how close the cube gets to the goal.
  • Imagined quality: run the same plans through the corrupted imagination and score the imagined outcomes.
  • Then ask: does the flawed imagination still rank the plans correctly — and does it still pick a good one?
score 1Ranking accuracy — how well the imagined ordering of the 12 plans matches the true ordering score 2Regret — how much worse the plan you'd actually pick is, compared to the best one

Sanity checks first: with zero corruption, imagination reproduces reality exactly and ranks the plans perfectly. Every run is seeded and reproducible bit-for-bit, and the key predictions were written down before the data came in.

05 result 1

The error types are not created equal

  • Short horizon is surprisingly harmless: even seeing only the first quarter of the plan, ranking stays good (0.75).
  • Noise degrades gently and predictably as it grows.
  • Bias is catastrophic: at the same scale of error, ranking falls to zero — no better than shuffling the plans at random.
● bias ■ noise ▲ short horizon

Each point: 30 scenarios, error bars are 95% confidence intervals. X-axis is the measured outcome error in meters.

06 result 2 · the headline

Bias doesn't scramble your ranking.
It changes which plan you pick.

The cleanest comparison the design allows: take one bias condition and one noise condition with the same measured error, and compare them head-to-head on the same 30 scenarios.

same
ranking accuracy — no detectable difference
2×
the regret when you pick under bias

Why: random errors push each plan's imagined outcome in a different direction and largely cancel out when comparing. A consistent bias pushes all plans the same wrong way — which is exactly what fools the final choice.

A consistently-wrong world model costs a planner about twice as much as a randomly-wrong one with the same average error. If you're improving a world model for planning, fix the bias first.
07 a second judge

What if an AI has to judge the imagined outcomes by looking at them?

The results so far score outcomes from the simulator's internal state. But many real systems work differently: a vision-language model looks at the imagined images and judges them. That's the only setup where "blurry pictures" can matter at all.

First finding: getting an AI to judge reliably is its own problem. Asking it to rate each outcome 0–10 was too coarse — it couldn't even rank perfect images well. Asking it to estimate the cube-to-goal distance in centimeters worked much better.

How the AI judge is askedRanking accuracy on perfect images
"Rate this outcome 0–10"0.62 too weak
"Estimate the distance in cm"0.88 used

The full image-judged version of the curves is the immediate next step — the pipeline is built and tested; the run takes under an hour.

08 takeaway

From "how good is it?" to "how good is good enough?"

what exists now

  • A reusable instrument: a simulator that plays a world model whose error you can type, dose, and measure
  • The first demand curves: decision quality vs. measured error, per error type
  • A concrete, pre-registered finding: bias is what kills planning — not noise, not short horizons

what it enables

  • Any real world model can be dropped onto these curves as a single point: "your model's error profile predicts this much decision quality"
  • Image-judged curves (in progress) and a spatial-reasoning version of the same question
  • A principled answer to give any world-model builder: which error to fix first, and how low it must go
One sentence: I turned "how accurate must imagination be?" from a vibe into a measured curve — and the curve says consistency matters twice as much as precision.
